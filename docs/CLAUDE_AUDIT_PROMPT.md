Audita PacheVideo como si fuera a lanzarse mañana a clientes pagos. Trabaja en modo solo lectura: no edites ni crees archivos. Inspecciona web, server, companion, packaging, deploy, scripts y tests. Ejecuta únicamente pruebas no destructivas cuando ayuden. Busca fallas funcionales, carreras, seguridad, abuso, límites, archivos temporales, descargas parciales, integración frontend-backend, empaquetado Windows/macOS, PWA, despliegue y observabilidad. Distingue defectos reproducibles de riesgos externos inevitables. Prioriza P0, P1, P2 y P3. Para cada hallazgo incluye evidencia con archivo y línea, impacto, forma de reproducir y corrección concreta. Cierra con una lista mínima de pruebas que deben pasar antes del lanzamiento. Responde en español y no supongas que cualquier plataforma externa será estable para siempre.
